## ✨ Features
- Add, Edit, and Delete expenses
- Category-wise expense organization
- Month-wise filtering with total summary
- Interactive Pie Chart & Bar Chart analytics
- Offline-first with local Room Database
- Clean Material Design UI

## 🛠️ Tech Stack
| Layer        | Technology                   |
| Language     | Java                         |
| Architecture | MVVM                         |
| Database     | Room (SQLite)                |
| Charts       | MPAndroidChart               |
| UI           | Material Design 3            |
| Navigation   | Android Navigation Component |
| Async        | LiveData + ViewModel         |


## 🚀 Getting Started
1. Clone the repository
```bash
   git clone https://github.com/Bhavadharani-B/Personal-Expense-Tracker.git
```
2. Open in **Android Studio**
3. Let Gradle sync complete
4. Run on emulator or physical device (Min SDK 24)

## 📊 Architecture
This app follows the **MVVM (Model-View-ViewModel)** pattern:
- **Model** — Room Database entities and DAOs
- **View** — Activities and Fragments
- **ViewModel** — LiveData-powered business logic
